# YouTubeDownload

Персональная утилита для быстрого и бесплатного скачивания видеороликов и аудио с YouTube на macOS без рекламы, ограничений и навязчивых подписок.

## Документация проекта

- 📄 **[Техническое задание (ТЗ)](file:///Users/aplaygs/Documents/UtilitiesAplaygs/YouTubeDownload/TZ.md)** — полное описание проблемы, целей, функциональных и нефункциональных требований, сравнение технологий и архитектура.
- 📋 **[План реализации (PLAN.md)](file:///Users/aplaygs/Documents/UtilitiesAplaygs/YouTubeDownload/PLAN.md)** — пошаговый чек-лист разработки от подготовки окружения до интеграции с macOS (Spotlight/Terminal alias).

## Ключевой стек технологий
- **Движок**: `yt-dlp` (Python API) — максимальная скорость, поддержка до 4K/8K, регулярные обновления.
- **Медиапроцессор**: `FFmpeg` — мгновенное объединение адаптивных аудио/видео потоков без пережатия.
- **Интерфейс**:
  - **TUI (Терминал)**: `rich` + `questionary` — ультрабыстрый интерактивный выбор стрелочками.
  - **GUI (Окно macOS)**: `CustomTkinter` — графическое окно с превью и поддержкой темной темы.
  - **Личный бот (опция)**: `aiogram` — персональный Telegram-бот без чужой рекламы и с доступом только для владельца.
