# YouTubeDownload

Персональный загрузчик видео и аудио с YouTube для macOS без рекламы, подписок и ограничений по скорости и качеству.

---

## 🚀 Быстрый запуск

### 1. Из любого места в терминале (через команду `ytdl`)
После добавления алиаса скриптом `setup_alias.sh`:
```bash
# Интерактивное меню в терминале (со стрелочками и карточкой видео)
ytdl

# Прямое скачивание в Full HD со звуком
ytdl "https://www.youtube.com/watch?v=..."

# Скачивание только звука в MP3 (320 kbps)
ytdl -a "https://www.youtube.com/watch?v=..."

# Запуск графического окна
ytdl --gui
```

### 2. Запуск через скрипт `run.sh`
```bash
# Интерактивный TUI
./run.sh --cli

# Графический интерфейс (CustomTkinter)
./run.sh --gui
```

## ✨ Возможности

- **100% Бесплатно и без ограничений**: никаких спонсорских каналов, платных ботов и лимитов на размер файла.
- **Два интерфейса на выбор**:
  1. **TUI (Терминал)**: моментальный запуск, интерактивный выбор качества стрелками клавиатуры, цветной прогресс-бар Rich.
  2. **GUI (Графическое окно)**: современная темная тема macOS, предварительный просмотр превью видео, выбор папки в Finder.
- **Поддержка высокого качества**: 1080p Full HD (60fps), 2K, 4K Ultra HD со звуком, а также чистый MP3 320 kbps с обложкой.
- **Оптимизация для РФ без VPN**:
  - Автоматическое подключение JS Runtime (Node.js / macOS JavaScriptCore) для расшифровки YouTube n-sig подписей.
  - Высокая скорость загрузки (8–15 МБ/с) напрямую без замедления.
- **Интеграция с macOS**:
  - Автоподхват ссылки из буфера обмена.
  - Нативные системные уведомления по окончании загрузки.
  - Кнопка моментального открытия файла в Finder.

## ⚙️ Настройки (`config.json`)

Файл `config.json` создается автоматически при первом изменении настроек. Основные параметры:
- `download_dir`: путь сохранения (по умолчанию `~/Downloads/YouTube`).
- `preferred_resolution`: предпочтительное качество (`1080p`, `720p`, `4k`, `best`).
- `audio_format`: формат аудио (`mp3`, `m4a`).
- `proxy`: адрес прокси (при необходимости, например: `socks5://127.0.0.1:10808`).
