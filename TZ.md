# Техническое задание (ТЗ)
## Проект: Персональный загрузчик YouTube-видео (YouTubeDownload)

---

### 1. Введение и назначение системы
Настоящий документ определяет технические требования к разработке персонального программного решения для загрузки видео- и аудиоматериалов с платформы YouTube (а также других поддерживаемых медиахостингов).

#### 1.1. Обоснование разработки (Проблематика)
Существующие сторонние Telegram-боты и онлайн-сервисы обладают следующими критическими недостатками:
1. **Навязчивая монетизация**: требование подписки на 3–5 спонсорских каналов перед каждой загрузкой.
2. **Лимиты качества**: искусственное ограничение разрешения до 720p или 480p (видео 1080p, 2K, 4K требуют платных подписок).
3. **Ограничения по размеру файлов**: Telegram Bot API блокирует прямую отправку файлов тяжелее 50 МБ без сторонних серверов.
4. **Нестабильность**: боты регулярно блокируются YouTube или разработчики забрасывают их поддержку.
5. **Безопасность и приватность**: передача личной истории запросов и метаданных сторонним сервисам.

#### 1.2. Цель проекта
Создать независимую, бесплатную, высокоскоростную утилиту на локальном компьютере (macOS), обеспечивающую:
- Прямое скачивание без ограничений по скорости и размеру.
- Выбор любого доступного качества: от 360p до 4K/8K, а также чистого аудио (MP3/FLAC/M4A).
- Полностью русифицированный интерфейс.
- Удобство использования (консоль, графическое окно или личный закрытый бот).

### 2. Сравнительный анализ технологий

#### 2.1. Движок загрузки медиа
| Библиотека / Инструмент | Скорость и стабильность | Поддержка 1080p+ и 4K | Обход троттлинга YouTube | Актуальность поддержки | Вердикт |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **yt-dlp** | 🟢 Максимальная (многопоточность) | 🟢 Полная (видео + аудио сшивка) | 🟢 Регулярные патчи `n-sig` алгоритмов | 🟢 Обновления каждую неделю | **Выбор №1 (Стандарт индустрии)** |
| **pytube** | 🔴 Низкая | 🔴 Ограниченная (проблемы с потоками) | 🔴 Часто ломается с ошибками парсинга | 🔴 Проект фактически заброшен | ❌ Не рекомендуется |
| **youtube-dl** | 🟡 Средняя | 🟡 Базовая | 🔴 Медленное скачивание (троттлинг YouTube) | 🟡 Редкие релизы | ❌ Устарел, заменен на yt-dlp |

#### 2.2. Обработка медиапотоков (Медиапроцессор)
- **FFmpeg**: обязательный компонент. Начиная с 1080p, YouTube хранит видео и аудио в разных раздельных потоках (DASH adaptive streaming). Без FFmpeg скачивание 1080p/4K возможно только без звука.
- С FFmpeg загружаются параллельно наилучший видеопоток и лучший аудиопоток, после чего за 1–2 секунды без перекодирования (в режиме `-c copy`) объединяются в единый контейнер `.mp4` или `.mkv`.
- Для аудио: конвертация в MP3 с автоматическим прописыванием ID3-тегов (название, автор) и вшиванием превью-обложки (thumbnail).

#### 2.3. Варианты пользовательского интерфейса
| Форм-фактор | Технология | Плюсы | Минусы |
| :--- | :--- | :--- | :--- |
| **Интерактивный терминал (TUI)** | Python + `rich` + `questionary` | • Запуск мгновенный (`ytdl`)<br>• Выбор качества стрелками клавиатуры<br>• Стильный прогресс-бар, скорость, ETA<br>• Не тратит оперативную память | Нет мышиного интерфейса (хотя для большинства это быстрее) |
| **Графический интерфейс (GUI)** | `CustomTkinter` / `PyQt6` | • Окно в стиле macOS (Dark/Light)<br>• Поле ввода с кнопкой «Вставить»<br>• Выбор папки через стандартный Finder<br>• Отображение превью ролика | Требует отдельного запуска окна |
| **Локальный Web-интерфейс** | `NiceGUI` / `FastAPI + HTML` | • Работает в браузере (Safari / Chrome)<br>• Современный дизайн, адаптивность | Работа локального сервера на порту |
| **Личный Telegram-бот** | `aiogram 3.x` (Self-hosted) | • Можно кидать ссылки с телефона<br>• Скачивает прямо на Mac (в папку «Загрузки»)<br>• Доступ только для вашего Telegram ID | Mac должен быть включен во время запроса |

### 3. Функциональные требования

#### 3.1. Получение и валидация ссылки
- Поддержка ссылок вида:
  - `https://www.youtube.com/watch?v=...`
  - `https://youtu.be/...`
  - `https://www.youtube.com/shorts/...`
  - Ссылок с таймкодами (таймкод игнорируется при скачивании всего видео).
  - Ссылок на плейлисты (с возможностью скачать весь плейлист или конкретное видео).
- Автоматическое чтение из буфера обмена macOS (если в буфере ссылка на YouTube — предлагать её сразу).

#### 3.2. Извлечение информации (Инфо-панель)
Перед скачиванием программа отображает пользователю:
- Название видеоролика.
- Имя канала / автора.
- Продолжительность (ЧЧ:ММ:СС).
- Размер предполагаемой загрузки для каждого варианта качества.

#### 3.3. Меню выбора форматов (на русском языке)
1. **Видео с наилучшим качеством** (автоматический выбор максимального доступного разрешения со звуком).
2. **Выбор конкретного разрешения видео**:
   - `4K (2160p)`
   - `2K (1440p)`
   - `Full HD (1080p, 60fps)`
   - `HD (720p)`
   - `SD (480p / 360p)`
3. **Только звук (Аудио)**:
   - `MP3 (Высокое качество, 320 kbps)`
   - `M4A (Исходный AAC звук без перекодирования)`
   - `FLAC / WAV (Без сжатия)`
4. **Субтитры** (опция: скачать субтитры на русском или английском языках).

#### 3.4. Процесс загрузки и индикация
- Отображение прогресса в реальном времени:
  - Графический процент выполнения (`[████████░░] 80%`).
  - Скорость загрузки (например: `18.5 MB/s`).
  - Скачанный объем / общий объем (например: `142.3 MB / 178.0 MB`).
  - Расчетное оставшееся время (ETA, например: `00:02`).

#### 3.5. Сохранение и организация файлов
- Папка сохранения по умолчанию: `~/Downloads/YouTube` или настраиваемая директория.
- Формат имени файла: `[Название видео] - [Качество].mp4` (с автоматической очисткой недопустимых символов в именах файлов macOS).
- По завершении скачивания:
  - Системное уведомление macOS.
  - Опция моментального открытия папки в Finder.

### 4. Нефункциональные требования

1. **Бесплатность и открытость**: отсутствие платных API, ключей, подписок и закрытых проприетарных сервисов.
2. **Скорость работы**:
   - Старт парсинга видео — не более 1.5–2 секунд.
   - Скорость скачивания — ограничена только интернет-каналом пользователя (многопоточная загрузка через `yt-dlp`).
   - Склейка через FFmpeg — до 3 секунд для видео длиной 15–20 минут.
3. **Локализация**: весь пользовательский интерфейс, системные сообщения, ошибки и подсказки строго на русском языке.
4. **Отказоустойчивость**:
   - Корректная обработка ошибок (видео с ограниченным доступом, 404, отсутствие интернет-соединения).
   - Поддержка механизма возобновления скачивания при обрыве связи.

### 5. Архитектура программного комплекса

Проект строится по модульному принципу (слоистая архитектура), разделяя логику скачивания и интерфейсы:

```
YouTubeDownload/
├── core/                   # Ядро загрузки (не зависит от интерфейса)
│   ├── __init__.py
│   ├── downloader.py       # Интеграция с yt-dlp, хуки прогресса
│   ├── extractor.py        # Парсинг информации о видео и форматах
│   └── config.py           # Настройки (папки, шаблоны имен, предпочтения)
├── interfaces/             # Пользовательские интерфейсы
│   ├── cli/                # Терминальный интерактивный интерфейс (TUI)
│   │   ├── __init__.py
│   │   └── app.py          # Меню на Rich + Questionary
│   ├── gui/                # Графический интерфейс (Desktop окно)
│   │   ├── __init__.py
│   │   └── window.py       # Окно на CustomTkinter/PyQt
│   └── bot/                # (Опционально) Персональный закрытый TG-бот
│       ├── __init__.py
│       └── telegram_bot.py # Управление по личному chat_id
├── utils/                  # Вспомогательные утилиты
│   ├── __init__.py
│   ├── clipboard.py        # Работа с буфером обмена macOS
│   └── system.py           # Уведомления macOS, открытие Finder
├── main.py                 # Главная точка входа
├── config.json             # Файл пользовательских настроек
├── requirements.txt        # Список зависимостей Python
├── run.sh                  # Исполняемый скрипт быстрого запуска для macOS
├── TZ.md                   # Данный документ ТЗ
└── PLAN.md                 # Пошаговый план разработки и внедрения
```

### 6. Критерии приемки
1. Утилита успешно запускается одной командой на macOS.
2. При подаче ссылки на YouTube-видео пользователю предлагается выбор качества на русском языке.
3. Ролик в качестве 1080p или 4K скачивается со звуком в формате MP4 без рассинхронизации.
4. При выборе аудио скачивается качественный MP3 с метаданными.
5. Загруженный файл корректно открывается стандартным QuickTime Player / IINA / VLC.
