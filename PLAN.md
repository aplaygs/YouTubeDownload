# План реализации проекта: Персональный загрузчик YouTube (YouTubeDownload)
## Обновленная версия: с частыми Git-коммитами, контролем качества и подробными комментариями

Пошаговый план разработки, настройки и интеграции на macOS.

---

## Принципы разработки
1. **Частые атомарные Git-коммиты**: каждый законченный логический блок (инициализация, ядро, утилиты, CLI, GUI, тесты) фиксируется отдельным коммитом с понятным описанием.
2. **Контроль качества (Code Review) на каждом шаге**: синтаксический анализ (`py_compile`), проверка типизации, обработка граничных случаев (обрыв сети, 403, таймауты, недопустимые символы в путях).
3. **Оптимизация под РФ без VPN**: использование стратегии каскадного перебора клиентов YouTube (`android -> ios -> mweb -> web`) в `yt-dlp` для обхода замедления ТСПУ.
4. **Подробное комментирование**: весь исходный код сопровождается подробными комментариями на русском языке и понятными docstrings.

## Этап 2. Разработка и аудит ядра системы (`core/`)
- [ ] **2.1. Конфигурация (`core/config.py`)**:
  - Каталог загрузок по умолчанию (`~/Downloads/YouTube`).
  - Настройки клиентов YouTube для обхода замедления в РФ без VPN (`android`, `ios`, `web`).
  - Поддержка прокси (HTTP/SOCKS5) с возможностью быстрого включения в `config.json`.
  - Детальные комментарии на русском языке к каждому параметру.
- [ ] **2.2. Парсер информации (`core/extractor.py`)**:
  - Быстрое получение метаданных (название, автор, длительность, обложка).
  - Группировка форматов: 4K, 2K, 1080p, 720p, 480p и аудио (MP3 320 kbps, M4A).
  - Обработка ошибок (ограничения доступа, приватные видео, 404).
- [ ] **2.3. Загрузчик медиа (`core/downloader.py`)**:
  - Интеграция с `yt-dlp` и `ffmpeg`.
  - Автоматическая склейка видео и аудио без перекодирования в чистый `.mp4`.
  - Конвертация аудио в MP3 с метаданными и вшиванием обложки.
  - Потокобезопасный хук прогресса: процент, скорость передачи, ETA, размер файла.
  - Механизм автоповтора (retry) при нестабильной сети.
- [ ] **2.4. Аудит и проверка ядра**:
  - Тест извлечения информации без загрузки полного файла.
  - 💾 **Git Commit 3**: `feat(core): implement resilient downloader, extractor with Russia DPI bypass and config`.
